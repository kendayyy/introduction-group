# Design tokens

Corporate Systems Premium tokens live in `src/design/tokens.ts` and `src/app/globals.css`.

- Ink `#14212B`, teal `#1C6E7D`, copper `#B68A4A`
- Text `#1A1D1F`, muted `#5F6B73`
- Background `#FFFFFF`, surface `#F5F6F7`, border `#D9D9D9`
- Container maximum 1280 px, prose maximum 760 px
- Gutters 16 / 20 / 24 px
- Section space 72 / 96 / 128 px, inside the specified ranges
- Card radius 8 px
- Typography uses fixed sizes. The mobile hero is 32 px. Letter spacing is zero.
- Breakpoints: 375, 480, 768, 1024, 1200, 1440
- Focus is a 2 px teal outline. Nonessential motion is disabled for reduced motion.

The development preview is `/vi/dev/tokens` and is not indexed.
